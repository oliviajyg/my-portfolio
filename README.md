# portfolio

A desk of pictures and notes. Click a sticker to open it.

Live site: https://oliviajyg.github.io/my-portfolio/

## Local development

```bash
npm install
npm run dev
```

Open the URL Vite prints.

## Your pictures

Put image files in `public/photos/`, then point to them from `src/portfolio/data.ts`.

## Deploy

```bash
npm run deploy
```

That builds the portfolio and publishes it to GitHub Pages. The live site is https://oliviajyg.github.io/my-portfolio/.
